# Deep Agent

Enterprise-grade LangGraph-based deep agent framework with skills-driven architecture.

## Vision
A reusable framework enabling business desks to create custom AI agents by providing business logic in plain language (skills). Built on LangChain's Deep Agents + LangGraph, designed to scale to 100s of agents.

## Architecture
- **Core:** LangGraph deep agent harness with code execution
- **Skills:** Plain-language business logic that instructs agents
- **Data:** Multi-database support (Redis, Mongo, ClickHouse, MySQL)
- **Integration:** MCP servers, custom APIs, Python libraries
- **Future-proof:** Designed for easy swap to Claude Agent SDK
